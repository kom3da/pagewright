# サイトを更新する（公開サイトへの反映）

Pagewright の公開サイトは、管理画面で書いた内容から作った「できあがりのページ」の集まりです。
内容を変えると、公開サイトが自動で作り直されます。この作り直しを「サイトの更新」と呼びます。

## 自動で更新されるとき

次の操作をすると、公開サイトが自動で更新されます。ふだんは何もしなくてかまいません。

- 記事や固定ページを「公開する」「変更を公開する」「公開をやめる」「削除する」
- 予約した日時になって、自動で公開されたとき
- カテゴリやタグを追加・変更・削除したとき
- 「サイトの設定」を保存したとき

反映はふつうすぐ終わりますが、ページが多いサイトでは少し時間がかかります。公開サイトを開いても変わっていないときは、少し待ってから、ブラウザで再読み込みしてください。

## 更新の結果を確かめるには

ホームの「公開サイトの更新」の枠に、最後の更新の結果が出ます。

| 表示 | 意味と、すること |
| --- | --- |
| 前回の更新はうまくいきました | 問題ありません。「最後の更新」に日時が出ます |
| 前回の更新がうまくいきませんでした | 公開サイトを作り直せませんでした。下の「サイトを更新」を押します |
| 気をつけること（○件） | 公開サイトにうまく出せなかったものがあります。書いてある記事やページを直します |
| 公開サイトはまだできていません | まだ何も公開していません。記事やページを公開すると、自動で作られます |

## 手で更新するには

公開サイトの表示がおかしいときや、更新に失敗したときは、手で更新します。

1. ホームの「公開サイトの更新」の枠の「サイトを更新」を押します。
2. 「サイトの更新を始めました。」と出ます。終わると、枠に結果が出ます。

「サイトを更新」は、公開サイト全体を作り直します。ふだんは押さなくてかまいません。
何度押しても失敗するときは、サイトを作った会社や担当者に連絡してください。そのとき、枠の「くわしい内容」に出ている文を伝えると、原因を調べやすくなります。

## 公開サイトを見るには

- メニューのいちばん下の「公開サイトを見る」を押すと、公開サイトのトップページが新しいタブで開きます。
- 記事や固定ページの編集画面で「公開中のページを見る」を押すと、そのページが開きます。
- 一覧のタイトルの下の URL を押しても開きます。
