# はじめての記事（画像つきのお知らせを出す）

写真を1枚入れた「お知らせ」の記事を書いて、公開サイトに出すまでを、順にやってみます。
1つ1つの操作のくわしい説明は、それぞれのページにあります。

## 0. 「お知らせ」のカテゴリを用意する

記事を「お知らせ」に分けるために、カテゴリを作っておきます。もうあれば、飛ばします。

1. メニューの「カテゴリ」を押し、「カテゴリを追加」を押します
2. 「カテゴリの名前」に `お知らせ`、「カテゴリのURL（英数字）」に `news` と入れて、「追加する」を押します

（くわしくは「[カテゴリとタグ](./taxonomy.md)」。）

## 1. 記事を書きはじめる

1. メニューの「記事」を押し、「記事を書く」を押します
2. 「タイトル」に、たとえば `年末年始の営業のお知らせ` と入れます
3. 「本文」に、お知らせの文を書きます。Enter で段落が分かれます

## 2. 写真を入れる

1. 本文の、写真を入れたい場所にカーソルを置きます
2. 本文の上のツールバーの「画像」を押します
3. 「新しい画像をアップロード」の「画像ファイル」で、写真を選びます（JPEG・PNG・GIF・WebP、10MB まで）
4. 「画像の説明（代替テキスト）」に、写真の中身を短く書きます。例：`店舗の入口と、年末年始の休業の貼り紙`
5. 「アップロードして入れる」を押します

- 写真は、本文の中の1つの段落のように、その場所に1枚で並びます。元の大きさで出て、本文の幅より大きいときは本文の幅に縮みます
- 写真の大きさや位置（右寄せなど）を変えたり、写真の下に説明（キャプション）を付けたりすることはできません。説明は、写真の前後の文に書きます
- 本文に入れたあとで「画像の説明」を直すときは、写真を消して、入れ直します（「[画像](./images.md#画像の説明-代替テキスト)」）

## 3. カテゴリと URL を決める

1. 右の「カテゴリとタグ」の枠で、「お知らせ」にチェックを付けます（スマートフォンでは本文の下にあります）
2. 右の「URL」の枠の「ページのURL（英数字）」に、たとえば `year-end-2026` と入れます。空のままなら、番号の URL（`/posts/12/` など）になります
3. 「下書き保存」を押します

## 4. 見た目を確かめる

1. 上の「プレビューを見る」を押します。新しいタブで、公開サイトと同じ見た目のページが開きます
2. 文や写真を直したいときは、編集画面に戻って直し、もう一度「下書き保存」を押します

ほかの人に見てもらいたいときは、「確認用のリンク」を作って送れます（「[記事を書く・公開する](./posts.md#ほかの人に見せるには-確認用のリンク)」）。

## 5. 公開する

1. 「公開する」を押します
2. 「公開しました。」と出たら、少し待ってから、メニューのいちばん下の「公開サイトを見る」を押します

公開サイトでは、次の場所にこの記事が出ます（標準のテーマ「コーポレート」の場合）。

| 場所 | 出るもの |
| --- | --- |
| トップページの「お知らせ」 | 新しい記事5件の、日付・カテゴリ・タイトル |
| お知らせの一覧（`/posts/`） | 10件ずつ、日付・カテゴリ・タイトル |
| 「お知らせ」のカテゴリの一覧（`/posts/category/news/`） | このカテゴリの記事 |
| 記事のページ | タイトル、日付、カテゴリ、本文と写真 |

一覧には写真は出ません（記事ごとの「アイキャッチ画像」はありません）。記事を書いた人の名前も、公開サイトには出ません。

## 公開したあとで直すには

公開した記事を直したときは、「保存（まだ公開しない）」では公開サイトは変わりません。「変更を公開する」を押すと、公開サイトに出ます（「[公開したあとで直すには](./posts.md#公開したあとで直すには)」）。
