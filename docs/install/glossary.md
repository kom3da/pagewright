# 用語集

導入・運用のページに出てくる言葉の意味です。

| 言葉 | 意味 |
| --- | --- |
| A レコード・AAAA レコード | DNS の設定の1つ。ドメインを、サーバーの IPv4 アドレス（A）・IPv6 アドレス（AAAA）に結びつけます |
| canonical | 「このページの正式なURLはこれです」と検索エンジンに伝える印。Pagewright は公開サイトの各ページに自動で付けます |
| Caddy | HTTPS の証明書を自動で取って、閲覧者からの接続を受けるソフト。標準の構成に入っています |
| cron | 決まった時刻にコマンドを自動で動かす、Linux のしくみ。バックアップを毎日取るのに使います |
| DKIM | メールに電子的な署名を付けて、そのドメインの持ち主が送ったことを確かめられるようにするしくみ（「[メール送信サービスを用意する](./mail.md)」） |
| DNS | ドメイン名から、サーバーの IP アドレスを調べるしくみ |
| Docker・Docker Compose | ソフトを「コンテナ」という箱に入れて動かすしくみ（Docker）と、いくつものコンテナをまとめて動かす道具（Docker Compose）。Pagewright の構成は `compose.yaml` に書いてあります |
| `.env` | 設定ファイル。ドメインやパスワードを書きます。パスワードが入るので、ほかの人に見せません |
| implicit（TLS） | メールの送信で、つないだ最初から暗号化して話すやり方。465 番ポートで使われます |
| Let's Encrypt | HTTPS の証明書を無料で発行する機関。Caddy がここから証明書を取ります |
| nginx | 公開サイトのファイルを配信し、管理画面への接続を本体へ中継するソフト |
| PostgreSQL | データベースのソフト。記事やユーザーなどを保存します |
| SMTP | メールを送るための決まった方法 |
| SPF | 「このドメインのメールは、このサービスから送ります」と DNS で宣言するしくみ |
| STARTTLS | メールの送信で、つないだあとに暗号化に切り替えるやり方。587 番ポートで使われます |
| WXR | WordPress の「ツール → エクスポート」で書き出すファイルの形式（中身は XML） |
| X-Forwarded-For | 間に入った中継サーバーが、元の閲覧者の IP アドレスを本体に伝えるための情報。ログインやお問い合わせの回数制限に使います |
| サイトのID | `init` で作ったサイトを見分ける番号（`0193xxxx-…` のような長い文字列）。`.env` の `PAGEWRIGHT_SITE_ID` などに書きます |
| サーバーの担当者 | サーバーに Pagewright を入れて、バックアップやアップデートをする人や会社。管理画面を使う人からの問い合わせ先になります |
| 静的ファイル | 開くたびに作るのではなく、前もって作っておいたページのファイル。Pagewright の公開サイトはこれなので、速く、管理画面が止まっていても表示されます |
| マイグレーション | Pagewright の版が上がったときに、データベースの形を新しい版に合わせて直すこと。起動のたびに自動で行います。一度行うと、版を戻しても元の形には戻りません |
| ユーザーID 10001 | Pagewright のコンテナの中で、本体が動くときの利用者の番号。バックアップの保存先などを、この番号の持ち主にしておく必要があります |
| リリースノート・変更履歴 | 版ごとに、何が変わったか・アップデートの前に何をすればよいかを書いたもの（[CHANGELOG.md](https://github.com/kom3da/pagewright/blob/main/CHANGELOG.md)） |
| ロードバランサー | クラウドなどで、閲覧者からの接続を受けてサーバーに振り分ける装置 |
