# 使う人に渡すもの

導入が終わったら、管理画面を使う人（記事を書く人、お問い合わせに答える人など）に、次のことを伝えます。

## 伝えること

| 伝えること | 例 |
| --- | --- |
| 管理画面のアドレス | `https://admin.example.co.jp/`（ブックマークしてもらう） |
| 公開サイトのアドレス | `https://www.example.co.jp/` |
| 登録したメールアドレス | その人のメールアドレス。ログインのときに入れます |
| ログインのしかた | パスワードはなく、毎回メールで届くリンクでログインします。リンクは15分で切れます |
| ログインのメールの差出人と件名 | 差出人は `.env` の `PAGEWRIGHT_MAIL_FROM`（例：「ウェブサイト管理」）、件名は「Pagewright ログイン用のリンク」。迷惑メールに入ったときに探せるように |
| 役割 | 「管理者」か「編集者」か。お問い合わせを見たり、サイトの設定を変えたりできるのは管理者だけです |
| 困ったときの連絡先 | サーバーの担当者（あなた）の連絡先 |
| 使い方の説明 | 「[使い方](../guide/)」のページ |

メンバーの追加は「メンバーと招待」のページ（準備中）で説明します。

## 文面の例

そのまま送れる文面の例です。`<>` の中を書き換えて使ってください。

```
件名：ホームページの管理画面のご案内

<お名前> 様

ホームページの管理画面を用意しました。

管理画面：https://admin.example.co.jp/
ご登録のメールアドレス：<メールアドレス>
役割：<管理者／編集者>

ログインにパスワードはありません。
管理画面を開いてメールアドレスを入れると、「Pagewright ログイン用のリンク」という件名のメールが届きます。
差出人は「ウェブサイト管理」です。リンクは15分で切れるので、届いたらすぐに開いてください。

使い方：<使い方のページのURL>
わからないことは <連絡先> までご連絡ください。
```

## 先に決めておくとよいこと

- **お問い合わせの通知の送り先**：管理画面の「サイトの設定」の「お問い合わせの送り先メールアドレス」。空欄なら、そのサイトの管理者全員に届きます
- **サイトの名前・ロゴ・メニュー**：管理者が「サイトの設定」で決めます（「[サイトの設定](../guide/settings.md)」）
- **個人情報の取り扱いのページ**：お問い合わせフォームを使うなら、固定ページで作って「サイトの設定」で選びます
